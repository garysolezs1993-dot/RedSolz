# Generated Art Assets

These atlases are visual source assets based on the supplied Red Riding Hood reference.

Important: the atlas contains labels and grouped panels, so it is not yet a clean per-frame SpriteFrames sheet. Use it as the project's art atlas/reference while building the prototype.

Recommended Godot import settings for final sprites:
- Texture Filter: Nearest
- Repeat: Disabled
- Red/player frame size: 32x32
- Wolf frame size: 32x32
- Standard enemies: 32x32
- Grandma boss: 32x32 or 48x48 depending on final scale
- Effects: separate sprites where possible
