# Red Riding Hood — Natural Gothic Forest Background Assets

Based on the supplied forest concept sheet.

Use this pack as Codex/Godot visual reference:
- dark natural forest
- rocky moss-covered platforms
- roots, vines and uneven terrain
- red moon and distant gothic castle
- bridges, lanterns, graves, signs and crates
- waterfalls/streams, mist and foreground foliage
- restrained crimson accents

IMPORTANT:
The supplied image is an asset presentation/concept sheet. The exported
category PNGs are reference panels, not claimed to be perfectly sliced
production tiles. Do not automatically treat every tiny image in a panel
as an individual tile.

Recommended Godot approach:
far sky/moon -> distant mountains/castle -> far forest -> mid forest ->
playable terrain -> foreground trees/vines/fog.

Use nearest-neighbor filtering. Final modular terrain can be built at 32x32
or 64x64 once the exact tile boundaries are chosen.
